# LeadPilot AI - Database Contract Specification

## Schema Entities (Prisma ORM Model)

### 1. User
- `id` (String, PK, cuid)
- `email` (String, Unique)
- `name` (String)
- `passwordHash` (String)
- `role` (Enum: ADMIN, REVIEWER, VIEWER)
- `createdAt` / `updatedAt` (DateTime)

### 2. Lead
- `id` (String, PK, cuid)
- `fullName` (String)
- `workEmail` (String, Indexed)
- `normalizedEmail` (String, Indexed)
- `phoneNumber` (String, Optional)
- `normalizedPhone` (String, Optional)
- `companyName` (String)
- `companyWebsite` (String, Optional)
- `industry` (String)
- `companySize` (String)
- `serviceRequired` (String)
- `budgetRange` (String)
- `desiredTimeline` (String)
- `decisionAuthority` (String)
- `projectDescription` (String)
- `leadSource` (String)
- `idempotencyKey` (String, Unique, Optional)
- `status` (Enum: NEW, SCORED, IN_REVIEW, APPROVED, REJECTED, ARCHIVED)
- `category` (Enum: HOT, WARM, COLD, REVIEW_REQUIRED, Optional)
- `totalScore` (Int, Optional)
- `isDuplicate` (Boolean, Default: false)
- `duplicateOfId` (String, Optional)
- `crmSyncStatus` (Enum: PENDING, SYNCED, FAILED, Default: PENDING)
- `crmExternalId` (String, Optional)
- `createdAt` / `updatedAt` (DateTime)

### 3. LeadScore
- `id` (String, PK, cuid)
- `leadId` (String, FK to Lead)
- `budgetFitScore` (Int)
- `serviceFitScore` (Int)
- `urgencyScore` (Int)
- `authorityScore` (Int)
- `infoQualityScore` (Int)
- `totalScore` (Int)
- `confidence` (Float)
- `summary` (String)
- `scoreBreakdown` (Json)
- `risks` (Json)
- `missingInformation` (Json)
- `recommendedAction` (String)
- `aiProvider` (String)
- `aiModel` (String)
- `promptVersion` (String)
- `isDemoMode` (Boolean)
- `createdAt` (DateTime)

### 4. ScoringRule
- `id` (String, PK, cuid)
- `criterionKey` (String, Unique) -- budgetFit, serviceFit, urgency, authority, infoQuality
- `name` (String)
- `maxScore` (Int)
- `weight` (Float)
- `configJson` (Json)
- `updatedBy` (String)
- `updatedAt` (DateTime)

### 5. FollowUp
- `id` (String, PK, cuid)
- `leadId` (String, FK to Lead)
- `subject` (String)
- `body` (String)
- `category` (String)
- `status` (Enum: DRAFT, APPROVED, SENT, FAILED)
- `sentAt` (DateTime, Optional)
- `emailAdapter` (String, Default: Mailpit)
- `recipientEmail` (String)
- `createdAt` / `updatedAt` (DateTime)

### 6. Approval
- `id` (String, PK, cuid)
- `leadId` (String, FK to Lead)
- `userId` (String, FK to User)
- `action` (Enum: APPROVE, REJECT, ADJUST_SCORE, REQUEST_INFO)
- `previousCategory` (String)
- `newCategory` (String)
- `previousScore` (Int)
- `newScore` (Int)
- `notes` (String)
- `createdAt` (DateTime)

### 7. IntegrationEvent
- `id` (String, PK, cuid)
- `leadId` (String, FK to Lead)
- `system` (String) -- CRM, MAILPIT, SLACK, N8N
- `eventType` (String)
- `status` (Enum: SUCCESS, FAILED, RETRYING)
- `attempts` (Int, Default: 0)
- `maxAttempts` (Int, Default: 3)
- `lastError` (String, Optional)
- `nextRetryAt` (DateTime, Optional)
- `payload` (Json)
- `createdAt` / `updatedAt` (DateTime)

### 8. WorkflowRun
- `id` (String, PK, cuid)
- `workflowName` (String)
- `executionId` (String, Optional)
- `status` (Enum: SUCCESS, FAILED, RUNNING)
- `startedAt` (DateTime)
- `completedAt` (DateTime, Optional)
- `detailsJson` (Json, Optional)

### 9. AuditLog
- `id` (String, PK, cuid)
- `userId` (String, Optional)
- `action` (String)
- `entityType` (String)
- `entityId` (String)
- `previousValue` (Json, Optional)
- `newValue` (Json, Optional)
- `reason` (String, Optional)
- `ipAddress` (String, Optional)
- `createdAt` (DateTime)

### 10. Notification
- `id` (String, PK, cuid)
- `title` (String)
- `message` (String)
- `type` (Enum: HOT_LEAD, REVIEW_NEEDED, SYNC_ERROR, SYSTEM)
- `read` (Boolean, Default: false)
- `createdAt` (DateTime)

### 11. SystemSetting
- `id` (String, PK, cuid)
- `key` (String, Unique)
- `value` (Json)
- `updatedAt` (DateTime)
